Job Card Management

The Job Card is the central document for project execution. It captures critical structure data and serves as the source for sales commissions.

Approval Flow

DRAFT

Staff Create

Sales/Technical
→
SUBMITTED

Manager Review

Final Approval
→
APPROVED

Project Active

Commission Generated

How to Make Entries

  • Navigate to Job Cards > New.
  • Select the Requesting Department and Job Category.
  • Enter Structure Dimensions (e.g., 80x10m) and Location.
  • If creating for Sales, the system will auto-calculate a 3% commission upon manager approval.

Operational Expenses (OPEX)

All business expenditures must follow the multi-stage approval protocol before funds are disbursed.

The 4-Stage Protocol

STAGE 1

Request

Created: PENDING_ACCOUNTANT
→
STAGE 2

Verification

Accountant Set: APPROVED_ACCOUNTANT
→
STAGE 3

Authorization

Manager Set: APPROVED_FOR_PAYMENT
→
STAGE 4

Disbursement

Status: PAYMENT_PROCESSED

REJECTION NOTE: If rejected at any stage, the verifier must provide a comment. The request returns to the creator for adjustment.

Finance & Treasury

Real-time Ledger

The system maintains a holistic view of BANK, CASH, ECOCASH, and IRD accounts. Final Balances are calculated as: Income + Topups - (Paid Expenses + Transfers Out) + Transfers In.

Fund Transfers

Transfers between internal accounts require initialing by the ACCOUNTANT and final approval by the MANAGER.

Container Access Authorization (CAA)

Security protocol for physical inventory containers.

Operating Procedure

1. Request

Staff submits purpose, date, and time window.

2. Authorize

Manager approves and system generates a PDF.

3. Log

Staff must LOG each entry physical visit in the system.

Analytics & Audit

The system tracks "Accessed Count" and cross-references it with authorizations to ensure no unauthorized physical access occurs.
